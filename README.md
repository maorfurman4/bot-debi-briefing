בוט טלגרם ששולח כל בוקר הודעה אחת מסודרת להתחלת היום.

## מה בהודעה
1. "בוקר טוב מאור" — פתיח אחר לכל יום בחודש
2. מזג אוויר בתל אביב (Open-Meteo): טמפרטורה מקס'/מינ', זריחה ושקיעה
3. הלו"ז של היום מהיומן, לפי שעות, כולל חלונות פנויים של שעה ומעלה
4. 🗂️ monday — מכל הלוחות: רק מה שבדדליין **מחר, בעוד 3 ימים ובעוד שבוע**, ומה בסטטוס "תקוע"
   (בלי "בוצע" ובלי קבוצות ארכיון; הלוחות והעמודות נמצאים לפי שם — "סטטוס"/"דדליין" — לא לפי מזהה).
   בתוכנית Free של monday אין תזכורות — זה ערוץ התזכורות לדדליינים
5. 📋 קישור לרשימת המשימות של היום ביוסי. **משימות לעשות** (מתוכנן להיום, באיחור, דדליין היום, השגרה) — רק ברשימת ה-✅
   של יוסי ב-07:00, לא כאן (5.11: הופיעו פעמיים)
6. ⚠️ מה לא עבד — רק אם חלק נכשל (למשל Google Tasks או יומן), כדי שנדע מה לתקן

## מתי
כל יום ב-05:30 (שעון ישראל) — cron-job.org מפעיל את `.github/workflows/main.yml` (workflow_dispatch); ב-22:00 — mode=evening.
אפשר גם להריץ ידנית: Actions → "תדריך בוקר דבי" → Run workflow.
